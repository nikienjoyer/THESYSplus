What changes

  • Removed: the checkboxes, the "Add another thesis you cited…" search, and the Save citations button.
  • Saved automatically during upload, before this screen appears. The list is what is already stored.
  • 2 or more: all are listed, sorted by title, and all are saved. The list grows with the modal, which already scrolls; no inner scroll box.
  • Only exact title matches count. Author-and-year guesses are dropped, since no one confirms them anymore.
  • Student uploads are saved too, but only count toward "Cited by" once the thesis is approved (already how the counter works).
