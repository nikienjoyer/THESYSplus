Navbar: bigger without heavy boxes

Each bar is drawn at the real screen width you pick, then shrunk to fit here, so proportions match what you'd see on that monitor. Compare how much of the bar the links fill and how big the text is relative to the bar.

Today (main)
Current proposal: equal slots, pill fills the slot
Option 1 (recommended): spread out, pill hugs the word
Option 2: spread out, underline instead of a pill

Why the current proposal feels heavy: every link box is stretched to a fifth of 52–58% of the screen, so at 1920px the "Home" pill is about 200px wide around a 4-letter word. The box is far bigger than the text inside it.

Option 1: same bigger text, logo and bar height, and the links still spread across the same width. Only the spacing between links grows. The pill stays tight around each word (about 1em of side padding), so it reads as a label, not a block. This is a one-class change: drop xl:[&>li]:flex-1 and the link's block text-center, and add justify-between to the list.

Option 2: same spread, but the active page gets ink-colored text and a 2px blue line at the bottom edge of the bar, with no background box. Hover only changes the text color. It is the lightest look, but it moves away from the pill used elsewhere in the app (mobile drawer, tabs).
